# MLP Phase 2 Experiment: Artifact Preservation and Completeness Report

**Date of Audit**: 2026-11-18  
**Target Classifier**: Multi-Layer Perceptron (`MLPModel` / `MLPClassifier`)  
**Audit Directory**: `results/openset/MLP/features_48/`  
**Total Saved Artifacts**: 47 files (pre-audit inventory) + 1 audit report  
**Audit Scope**: Verification of physical file existence, readability, non-emptiness, numerical consistency, missing visualization/diagnostic identification, and cross-classifier comparison across all five Phase 2 models (LightGBM, Random Forest, XGBoost, Logistic Regression, and MLP).

---

## 1. Executive Summary

This report documents the dedicated **Experiment Artifact Preservation and Completeness Check** performed on the Phase 2 experimental artifacts for the **Multi-Layer Perceptron (MLP)** network intrusion detection model.

All 47 primary experiment files in `results/openset/MLP/features_48/` were physically inspected on disk. The inspection verified that:
1. **Physical Persistence**: All 46 core standard experimental artifacts (12 closed-set, 11 MSP, 11 Energy, and 12 OpenMax) plus the comprehensive execution report (`MLP_phase2_execution_report.md`) exist on disk, are non-empty, and are fully readable.
2. **Mathematical Consistency**: Numerical metrics recorded across JSON files, CSV summary tables, and confusion matrices match with 100% precision. Closed-set accuracy ($74.06\%$), Macro F1 ($49.33\%$), and Weighted F1 ($75.37\%$) align exactly with the trace and support of the $6 \times 6$ confusion matrix ($N=77,831$). Open-set metrics across MSP, Energy, and OpenMax align precisely with their respective $7 \times 7$ confusion matrices and per-category unknown detection tables ($N=82,332$).
3. **Execution Narrative Clarification**: The audit resolved an inconsistency in the narrative draft of the execution report regarding OpenMax at $\tau_{\text{FPR05}}$: the actual machine-readable JSON and CSV records confirm that known coverage is **80.83%** (62,911 / 77,831) and open-set accuracy is **66.75%** (54,960 / 82,332), which perfectly matches the saved $7 \times 7$ confusion matrix.
4. **Machine-Readable Completeness**: Complete trained neural network weights, biases, architecture, and scalers are preserved in `model.pkl` (367,477 bytes) and `preprocessor.pkl` (12,722 bytes). Raw training loss progression (`loss_curve_`, 45 epochs) and validation accuracy progression (`validation_scores_`, 45 epochs) are fully preserved inside the model object.
5. **Standardized Visualization Parity**: MLP contains the exact same 16 ultra-high-resolution (300 DPI) visualization plots present in LightGBM, Random Forest, XGBoost, and Logistic Regression.
6. **Diagnostic Gaps Across All Models**: Certain extended diagnostic plots (score distribution histograms, threshold calibration curves, training loss curves, and EVT diagnostic plots) were not generated by the baseline pipeline scripts and are missing across **all five classifiers**, representing a systemic pipeline characteristic rather than an MLP-specific omission.
